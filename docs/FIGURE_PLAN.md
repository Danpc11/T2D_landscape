# Figure plan — one claim per figure, several panels that prove it

Order follows the story: the organs share one state → that state drifts continuously → at rest the state is blind to insulin sensitivity → the healthy response is coordinated and clock-coupled → insulin resistance fragments it → adipose fails differently and interventions restore magnitude only.
